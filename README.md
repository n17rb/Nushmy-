# نشمي — تطبيق الزبون وتطبيق الكابتن ولوحة الإدارة

منصة نقل ركاب محلية للكرك. هذا المستودع يحتوي على:

- **الخادم (Backend/API)** — Node.js بدون أي مكتبات خارجية
- **قاعدة البيانات** — PostgreSQL في الإنتاج، SQLite تلقائياً للتجربة المحلية
- **تطبيق الزبون** — على الرابط الرئيسي `/`
- **تطبيق الكابتن** — على الرابط `/captain`
- **لوحة الإدارة** — على الرابط `/admin`
- **محرك التسعير** و **محرك التوزيع الذكي** و **آلة حالات الرحلة**

---

## 1) تشغيله على جهازك خلال دقيقة

تحتاج فقط Node.js إصدار 22.5 أو أحدث.

```bash
node --version      # لازم يكون v22.5 أو أعلى
npm start
```

ثم افتح المتصفح على: **http://localhost:3000**

لا يحتاج تثبيت أي حزمة، ولا يحتاج قاعدة بيانات: سيُنشئ ملف SQLite تلقائياً في `db/nashmi.db`.

### رمز التحقق أثناء التجربة
`SMS_PROVIDER=dev` هي الحالة الافتراضية، فيظهر رمز الدخول:
1. في سجل الخادم (Terminal)
2. وعلى شاشة إدخال الرمز داخل التطبيق داخل صندوق أصفر مكتوب عليه «وضع التطوير»

هذا **لا يعمل في وضع الإنتاج** إلا إذا ضبطت `OTP_DEV_SHOW=1` صراحةً (للمعاينة فقط).

## 3) النشر على Render + Neon

### أ) قاعدة البيانات على Neon
1. ادخل إلى [neon.tech](https://neon.tech) وأنشئ مشروعاً جديداً باسم `nashmi`.
2. انسخ **Connection String** (يبدأ بـ `postgresql://`).

### ب) الخادم على Render
1. ارفع هذا المجلد إلى مستودع على GitHub.
2. في [render.com](https://render.com) اضغط **New → Web Service** واختر المستودع.
3. الإعدادات:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Health Check Path**: `/api/health`
4. في **Environment** أضف:

| المفتاح | القيمة |
|---|---|
| `NODE_VERSION` | `22` |
| `NODE_ENV` | `production` |
| `JWT_SECRET` | قيمة عشوائية طويلة (انظر أدناه) |
| `DATABASE_URL` | رابط Neon الذي نسخته |
| `ADMIN_PHONES` | رقم هاتف المالك (مثل `0791234567`) — أكثر من رقم افصل بينهم بفاصلة. هذا الرقم يصير «مدير عام» تلقائياً |
| `SMS_PROVIDER` | `whatsapp` لإرسال الرمز على واتساب (أو `dev` للتجربة) — شوف القسم 5 |
| `OTP_DEV_SHOW` | `1` خلال المعاينة فقط حتى يظهر الرمز على الشاشة — **احذفه قبل الإطلاق** |
| `SERVICE_ALL_JORDAN` | `1` لتفعيل الخدمة بكل الأردن مؤقتاً — احذفه لترجع الخدمة للكرك فقط |
| `CAPTAIN_AUTO_APPROVE` | `1` يتفعّل الكابتن بدون مراجعة. **احذفه** حتى توافق أنت على كل كابتن من لوحة الإدارة |

لتوليد `JWT_SECRET`:
```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

5. اضغط **Create Web Service**. الجداول تُنشأ تلقائياً عند أول تشغيل.

### ج) الصور والوثائق
صور الحسابات ووثائق الكباتن وإشعارات CliQ تُحفظ **داخل قاعدة البيانات** (جدول `files`)،
فما بتنمسح لما يعيد Render التشغيل. الصور العامة تُقدَّم عبر `/media/<id>`،
والوثائق والإشعارات خاصة ولا يفتحها إلا المشرف عبر `/api/admin/files/<id>`.

## 4) لوحة الإدارة `/admin`

1. أضف رقمك في `ADMIN_PHONES` على Render.
2. افتح `https://<موقعك>/admin` وادخل برقمك ورمز التحقق.

ماذا تقدر تعمل:
- **لوحة القيادة**: رحلات ودخل وعمولة اليوم، رسم آخر 7 أيام، تنبيهات الكباتن والشحن المعلّقة.
- **الخريطة الحية**: كل الكباتن المتصلين والطلبات الجارية، تتحدث كل 5 ثوانٍ.
- **الرحلات**: بحث وفلترة، تفاصيل كاملة (المراحل، العروض المرسلة، المبالغ)، وإلغاء أي رحلة جارية.
- **الكباتن**: موافقة، رفض، إيقاف، حظر (مع سبب)، فصل، مراجعة الوثائق، وإضافة أو خصم رصيد.
- **شحن المحافظ**: مراجعة إشعار CliQ والموافقة (يضاف الرصيد مرة واحدة فقط مهما تكرر الضغط) أو الرفض.
- **العملاء**: بحث، تفاصيل ورحلات، إيقاف أو حظر (يطلع من التطبيق فوراً).
- **الأسعار**: تعديل كل أسعار كل نوع سيارة بكل منطقة، مع مثال مباشر لسعر رحلة.
- **الإعدادات**: العمولة، أدنى رصيد، اسم CliQ، إعدادات التوزيع والإلغاء، وتفعيل المناطق.
- **المشرفون**: إضافة مساعدين بصلاحيات محددة (مالي، تشغيل، دعم، مراقب).
- **سجل العمليات**: كل إجراء حساس مسجّل: مين، إمتى، قبل وبعد، والسبب.

## 5) تشغيل الرسائل الحقيقية (OTP)

الرمز يصل عبر مزوّد قابل للتبديل من `src/services/otp.js`.

**واتساب (WhatsApp Cloud API من Meta)** — الطريقة المعتمدة حالياً:
```
SMS_PROVIDER=whatsapp
WHATSAPP_TOKEN=...              # رمز الوصول (سرّي)
WHATSAPP_PHONE_NUMBER_ID=...    # Phone Number ID
WHATSAPP_TEMPLATE=nashmi_otp    # اسم قالب المصادقة
WHATSAPP_TEMPLATE_LANG=ar
```
واتساب ما بيسمح يبعت نص حر لرقم ما راسلك قبل، فلازم **قالب مصادقة (Authentication)** معتمد
فيه زر «نسخ الرمز». إذا فشل الإرسال و`OTP_DEV_SHOW=1` موجود، الرمز بيطلع على الشاشة مع سبب الفشل
(فترة المعاينة فقط).

**Twilio** (يعمل في الأردن):
```
SMS_PROVIDER=twilio
TWILIO_ACCOUNT_SID=...
TWILIO_AUTH_TOKEN=...
TWILIO_FROM=+1...
```
لإضافة مزوّد أردني محلي: أضف دالة جديدة داخل `providers` في نفس الملف بنفس الشكل،
ثم اضبط `SMS_PROVIDER` على اسمها. لا حاجة لتعديل أي شيء آخر في النظام.

## 6) بنية المشروع

```
nashmi/
├── src/
│   ├── server.js              الخادم والموجِّه وتقديم الملفات
│   ├── config.js              كل الإعدادات من متغيرات البيئة
│   ├── db/
│   │   ├── index.js           محوّل يعمل على PostgreSQL و SQLite
│   │   ├── schema.sql         كل الجداول والفهارس والمفاتيح
│   │   └── seed.js            المدن وأنواع المركبات والتسعير الابتدائي
│   ├── lib/                   JWT، التجزئة، التحقق، الأخطاء، السجلات
│   ├── services/
│   │   ├── money.js           حسابات مالية بالفلس (بدون أرقام عشرية)
│   │   ├── pricing.js         محرك التسعير من قاعدة البيانات
│   │   ├── dispatch.js        محرك التوزيع الذكي
│   │   ├── trip-state.js      آلة حالات الرحلة
│   │   ├── wallet.js          دفتر المحفظة (كل حركة مسجّلة وبدون تكرار)
│   │   ├── files.js           حفظ الصور والوثائق داخل قاعدة البيانات
│   │   ├── otp.js             رموز التحقق ومزوّد الرسائل
│   │   ├── settings.js        إعدادات النظام القابلة للتعديل
│   │   ├── auth.js            الجلسات والصلاحيات
│   │   └── geo.js             حسابات المسافة والزمن
│   └── routes/                auth · profile · places · trips · captain · admin
├── public/
│   ├── index.html             تطبيق الزبون
│   ├── captain/               تطبيق الكابتن
│   ├── admin/                 لوحة الإدارة
│   ├── css/tokens.css         ★ كل ألوان ومقاسات الهوية في مكان واحد
│   ├── css/                   app.css · captain.css · admin.css
│   ├── js/                    screens/ · captain/ · admin/
│   └── img/                   الشعار والكلمة والصورة
└── tests/                     اختبارات وحدات وتكامل
```

## 7) تعديل الهوية أو الأسعار

- **الألوان والخطوط والحواف**: `public/css/tokens.css` فقط. أي تغيير هناك ينعكس على كل الشاشات.
- **الأسعار والعمولة**: من لوحة الإدارة (صفحتي «الأسعار» و«الإعدادات»). لا يوجد أي رقم
  تسعير مكتوب داخل الكود؛ القيم الابتدائية فقط في `src/db/seed.js`.
