# نشمي — تطبيق الزبون وتطبيق الكابتن ولوحة الإدارة

منصة نقل ركاب محلية للكرك. هذا المستودع يحتوي على:

- **الخادم (Backend/API)** — Node.js بدون أي مكتبات خارجية
- **قاعدة البيانات** — PostgreSQL في الإنتاج، SQLite تلقائياً للتجربة المحلية
- **تطبيق الزبون** — على الرابط الرئيسي `/`
- **تطبيق الكابتن** — على الرابط `/captain`
- **لوحة الإدارة** — على الرابط `/admin`
- **محرك التسعير** و **محرك التوزيع الذكي** و **آلة حالات الرحلة**

---

## 1) تشغيله على جهازك خلال دقيقة

تحتاج فقط Node.js إصدار 22.5 أو أحدث.

```bash
node --version      # لازم يكون v22.5 أو أعلى
npm start
```

ثم افتح المتصفح على: **http://localhost:3000**

لا يحتاج تثبيت أي حزمة، ولا يحتاج قاعدة بيانات: سيُنشئ ملف SQLite تلقائياً في `db/nashmi.db`.

### رمز التحقق أثناء التجربة
`SMS_PROVIDER=dev` هي الحالة الافتراضية، فيظهر رمز الدخول:
1. في سجل الخادم (Terminal)
2. وعلى شاشة إدخال الرمز داخل التطبيق داخل صندوق أصفر مكتوب عليه «وضع التطوير»

هذا **لا يعمل في وضع الإنتاج** إلا إذا ضبطت `OTP_DEV_SHOW=1` صراحةً (للمعاينة فقط).

## 3) النشر على Render + Neon

### أ) قاعدة البيانات على Neon
1. ادخل إلى [neon.tech](https://neon.tech) وأنشئ مشروعاً جديداً باسم `nashmi`.
2. انسخ **Connection String** (يبدأ بـ `postgresql://`).

### ب) الخادم على Render
1. ارفع هذا المجلد إلى مستودع على GitHub.
2. في [render.com](https://render.com) اضغط **New → Web Service** واختر المستودع.
3. الإعدادات:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Health Check Path**: `/api/health`
4. في **Environment** أضف:

| المفتاح | القيمة |
|---|---|
| `NODE_VERSION` | `22` |
| `NODE_ENV` | `production` |
| `JWT_SECRET` | قيمة عشوائية طويلة (انظر أدناه) |
| `DATABASE_URL` | رابط Neon الذي نسخته |
| `ADMIN_PHONES` | رقم هاتف المالك (مثل `0791234567`) — أكثر من رقم افصل بينهم بفاصلة. هذا الرقم يصير «مدير عام» تلقائياً |
| `SMS_PROVIDER` | `whatsapp` لإرسال الرمز على واتساب (أو `dev` للتجربة) — شوف القسم 5 |
| `OTP_DEV_SHOW` | `1` خلال المعاينة فقط حتى يظهر الرمز على الشاشة — **احذفه قبل الإطلاق** |
| `SERVICE_ALL_JORDAN` | `1` لتفعيل الخدمة بكل الأردن مؤقتاً — احذفه لترجع الخدمة للكرك فقط |
| `CAPTAIN_AUTO_APPROVE` | `1` يتفعّل الكابتن بدون مراجعة. **احذفه** حتى توافق أنت على كل كابتن من لوحة الإدارة |

لتوليد `JWT_SECRET`:
```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

5. اضغط **Create Web Service**. الجداول تُنشأ تلقائياً عند أول تشغيل.

### ج) الصور والوثائق
صور الحسابات ووثائق الكباتن وإشعارات CliQ تُحفظ **داخل قاعدة البيانات** (جدول `files`)،
فما بتنمسح لما يعيد Render التشغيل. الصور العامة تُقدَّم عبر `/media/<id>`،
والوثائق والإشعارات خاصة ولا يفتحها إلا المشرف عبر `/api/admin/files/<id>`.

## 4) لوحة الإدارة `/admin`

1. أضف رقمك في `ADMIN_PHONES` على Render.
2. افتح `https://<موقعك>/admin` وادخل برقمك ورمز التحقق.

ماذا تقدر تعمل:
- **لوحة القيادة**: رحلات ودخل وعمولة اليوم، رسم آخر 7 أيام، تنبيهات الكباتن والشحن المعلّقة.
- **الخريطة الحية**: كل الكباتن المتصلين والطلبات الجارية، تتحدث كل 5 ثوانٍ.
- **الرحلات**: بحث وفلترة، تفاصيل كاملة (المراحل، العروض المرسلة، المبالغ)، وإلغاء أي رحلة جارية.
- **الكباتن**: موافقة، رفض، إيقاف، حظر (مع سبب)، فصل، مراجعة الوثائق، وإضافة أو خصم رصيد.
- **شحن المحافظ**: مراجعة إشعار CliQ والموافقة (يضاف الرصيد مرة واحدة فقط مهما تكرر الضغط) أو الرفض.
- **العملاء**: بحث، تفاصيل ورحلات، إيقاف أو حظر (يطلع من التطبيق فوراً).
- **الأسعار**: تعديل كل أسعار كل نوع سيارة بكل منطقة، مع مثال مباشر لسعر رحلة.
- **الإعدادات**: العمولة، أدنى رصيد، اسم CliQ، إعدادات التوزيع والإلغاء، وتفعيل المناطق.
- **المحادثات**: رسائل الزباين والكباتن للدعم الفني، الإبلاغ عن كابتن، الأغراض المنسية (مع زر «راسل الكابتن عن هاي الرحلة»)، وقراءة محادثات الرحلات وقت الشكاوى.
- **الإشعارات والعروض**: رسالة جماعية (مع كود خصم) للزباين أو الكباتن أو الكل — إشعار على التلفون + بتضل بصندوق الإشعارات.
- **الأماكن المشهورة**: محلات ومستشفيات وجامعات بتطلع أول نتيجة بالبحث.
- **صور السيارات**: صورة وحدة لكل فئة بترفعها أنت (بتتوحّد على نفس الإطار لحالها)، وقائمة بالفئات الناقصة حسب عدد الكباتن. التفاصيل: [`docs/CAR_STYLE_BIBLE.md`](./docs/CAR_STYLE_BIBLE.md).
- **التنبيهات**: كل ما كابتن يسجّل سيارة ما إلها صورة بيوصلك تنبيه (بالصفحة + إشعار على تلفونك).
- **المشرفون**: إضافة مساعدين بصلاحيات محددة (مالي، تشغيل، دعم، مراقب).
- **سجل العمليات**: كل إجراء حساس مسجّل: مين، إمتى، قبل وبعد، والسبب.

## 5) تشغيل الرسائل الحقيقية (OTP)

الرمز يصل عبر مزوّد قابل للتبديل من `src/services/otp.js`.

**الأسهل: من لوحة الإدارة ← «التحقق من الرقم».** فيها 4 خطوات بأزرار نسخ: App Secret، ربط الـ Webhook
(الرابط ورمز التحقق بيتولّدوا لحالهم)، نشر التطبيق وتجربة رسالة، وزر «شغّل التحقق بواتساب» — وهو ما بيشتغل إلا إذا
الفحص كله ✓، وبيرجع بكبسة. ما في داعي تعدّل Render لتغيير طريقة التحقق.

**الدخول بواتساب — الزبون بيبعت الرمز (الطريقة المعتمدة، بدون قالب وبدون سجل تجاري):**
```
SMS_PROVIDER=whatsapp_link
WHATSAPP_TOKEN=...              # رمز الوصول (سرّي)
WHATSAPP_PHONE_NUMBER_ID=...
WHATSAPP_WABA_ID=...
WHATSAPP_VERIFY_TOKEN=...       # كلمة سر بتختارها وبتحطها بـ Meta عند ربط الـ Webhook
WHATSAPP_APP_SECRET=...         # App Secret من إعدادات التطبيق بـ Meta (للتأكد إن الرسائل من واتساب)
```
التطبيق بيعطي الزبون رمز من 6 أرقام وزر بيفتح واتساب برسالة جاهزة لرقم نشمي. لما يبعتها، Meta بتوصلها لـ
`/api/whatsapp/webhook` (موقّعة)، منتأكد إنها من نفس الرقم، ومنفتح الجلسة. رسائل الزبون وردودنا مجانية.
لازم: ربط الـ Webhook بـ Meta (Callback URL + Verify token + الاشتراك بـ messages)، و«ربط الاستقبال» من صفحة واتساب،
ونشر التطبيق (Live) — سياسة الخصوصية على `/privacy`.

**احتياط SMS للي ما عنده واتساب — من تلفون أندرويد برقمك (أرخص إشي):**
```
SMS_FALLBACK=android
SMSGATE_USERNAME=...   # من تطبيق SMS Gateway for Android (وضع Cloud server)
SMSGATE_PASSWORD=...
```
بشاشة الدخول بواتساب بيطلع زر «ما عندي واتساب — ابعتلي الرمز برسالة SMS». الرسالة بتطلع من شريحة التلفون،
وتكلفتها حسب باقتك. التلفون لازم يضل شغال ومشحون وعلى الإنترنت.

**واتساب بقالب — نشمي بيبعت الرمز** (بده توثيق نشاط تجاري عند Meta):
```
SMS_PROVIDER=whatsapp
WHATSAPP_TOKEN=...              # رمز الوصول (سرّي)
WHATSAPP_PHONE_NUMBER_ID=...    # Phone Number ID
WHATSAPP_WABA_ID=...            # WhatsApp Business account ID (لصفحة «واتساب» بلوحة الإدارة)
WHATSAPP_TEMPLATE=nashmi_otp    # اسم قالب المصادقة
WHATSAPP_TEMPLATE_LANG=ar
```
واتساب ما بيسمح يبعت نص حر لرقم ما راسلك قبل، فلازم **قالب مصادقة (Authentication)** معتمد
فيه زر «نسخ الرمز». إذا فشل الإرسال و`OTP_DEV_SHOW=1` موجود، الرمز بيطلع على الشاشة مع سبب الفشل
(فترة المعاينة فقط).

**صفحة «واتساب» بلوحة الإدارة** (`/admin#/whatsapp`): بتفحص كل إشي مع Meta مباشرة (رمز الوصول، تسجيل الرقم،
الاسم المعروض، مراجعة الحساب، القالب) وبتعرض السبب الحقيقي لأي رفض، وفيها زر **إنشاء القالب** وزر **إرسال رمز تجربة**.

**Twilio** (يعمل في الأردن):
```
SMS_PROVIDER=twilio
TWILIO_ACCOUNT_SID=...
TWILIO_AUTH_TOKEN=...
TWILIO_FROM=+1...
```
لإضافة مزوّد أردني محلي: أضف دالة جديدة داخل `providers` في نفس الملف بنفس الشكل،
ثم اضبط `SMS_PROVIDER` على اسمها. لا حاجة لتعديل أي شيء آخر في النظام.

## 4.4) المكالمة داخل التطبيق

الزبون والكابتن بيحكوا من التطبيق بدون رصيد وبدون ما يبين رقم حدا للثاني. الصوت بيمشي بين التلفونين مباشرة (WebRTC)،
والسيرفر بس بيمرّر رسائل الربط. الطرف الثاني بيوصله إشعار «عم يتصل فيك» حتى لو التطبيق مسكّر.

- الإعدادات (لوحة الإدارة ← الإعدادات ← المكالمة داخل التطبيق): تشغيل/إيقاف، خادم STUN (جاهز)، وخادم **TURN** اختياري.
- TURN بيلزم لما التلفونين على شبكات موبايل مقفلة. أي خدمة TURN بتزبط — حط الرابط والمستخدم والباسورد.
- بدون TURN معظم المكالمات بتربط، والي ما بتربط بيطلعلها «تعذّر الاتصال — جرّب اتصال عادي» مع زر الاتصال العادي.

## 4.5) الإشعارات على التلفون (متل إنستقرام)

- **أندرويد والكمبيوتر**: الزبون أو الكابتن بيكبس «تفعيل الإشعارات» (من صفحة الإشعارات، والكابتن بيطلعله الطلب أول ما يتصل). ما في أي إعداد عليك — المفاتيح بتتولّد لحالها.
- **آيفون**: لازم «إضافة للشاشة الرئيسية» من Safari أول (iOS 16.4+)، وبعدين تفعيل الإشعارات من داخل التطبيق.
- **تطبيقات Google Play و App Store**: لما تغلّف التطبيق (مثلاً بـ Capacitor)، التطبيق بيسجّل رمز Firebase على `POST /api/push/register`، وأنت بتحط ملف Service Account بمتغير `FCM_SERVICE_ACCOUNT`.
- الكابتن بيوصله إشعار بكل طلب جديد حتى لو الشاشة مطفية، والزبون بيوصله «الكابتن قبل» و«الكابتن وصل» ورسائل الكابتن وردود الدعم.

## 7) تعديل الهوية أو الأسعار

  تسعير مكتوب داخل الكود؛ القيم الابتدائية فقط في `src/db/seed.js`.
